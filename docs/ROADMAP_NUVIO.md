# خطة CINEMAX ليكون شبيهًا بـ Nuvio

## لماذا التطبيق يبدو "فاشلًا" الآن — تشخيص صريح

1. **لا يوجد هيكل تنقّل.** كل شيء داخل شاشة واحدة طويلة (شعار + بطاقة + قائمة إضافات + كتالوج)، بلا تبويبات ولا شاشة تفاصيل ولا شاشة إعدادات مستقلة. أي تطبيق بهذا الشكل يبدو نموذجًا تقنيًا لا تطبيقًا.
2. **كل شيء داخل نوافذ منبثقة (`Dialog`).** الإعدادات، التفاصيل، اختيار المصادر، ومشغّل الفيديو نفسه. Nuvio يفتح التفاصيل كشاشة كاملة، والمشغّل بملء الشاشة، والنوافذ تبقى للأشياء الصغيرة فقط.
3. **الشاشة الرئيسية ليست "فنًّا أولًا".** Nuvio يبدأ ببوستر/لوجو بعرض الشاشة + سطر معلومات + زر واحد أبيض + نقاط تنقّل، ثم صفوف بوسترات. عندنا فيلم واحد مكبّر وبعده قائمة نصية.

الخبر الجيد: **Nuvio نفسه مبني على نفس تقنيتنا** (Kotlin Multiplatform + Compose Multiplatform، وعلى iOS يستخدم libmpv عبر جسر أصلي) — أي لا يوجد سبب تقني يمنعنا من الوصول إلى نفس المستوى. الفرق كله في **الواجهة والترتيب والصقل**، ونحن نملك أصلًا: مشغّل MPV، إضافات Stremio، مزوّدي Nuvio، ترجمات مدمجة، متابعة المشاهدة، وبحث شامل.

## ما نملكه اليوم (لا نبدأ من الصفر)

| موجود | ناقص |
| --- | --- |
| مشغّل libmpv داخلي (MKV/HEVC/ASS) | غلاف تحكم بملء الشاشة، إيماءات، PiP |
| إضافات Stremio كاملة (manifest/catalog/meta/stream/subtitles) | صفوف كتالوج متعددة في الرئيسية |
| مزوّدو Nuvio (JavaScriptCore) | دعم `cheerio`/`crypto-js` لبعض المزوّدين |
| بحث شامل داخل كل الإضافات | شاشة بحث بتبويب + سجل بحث |
| متابعة المشاهدة والمفضلة محليًا | تبويب مكتبة بشبكة بوسترات وفلاتر |
| ترجمات خارجية ومدمجة + اختيار المسار | تأخير الترجمة، تنسيق الترجمة، انتخاب الصوت |
| مكوّنات واجهة جاهزة غير مستخدمة (`CinemaxBottomBar`, `CinemaxRow`, `CinemaxPosterCard`) | ربطها وتشغيلها فعليًا |
| لا محرك تورنت | مصدر روابط تورنت (خارج نطاق هذه الخطة، يحتاج قرارًا منفصلًا) |

## خطة المراحل

### المرحلة 0 — هيكل التنقّل (أساس كل شيء)
**الملفات:** `AppShell.kt` جديد + `MainViewController.kt`.
1. شاشة الجذر تحمل `selectedTab` وأربعة تبويبات: الرئيسية، بحث، مكتبتي، إعدادات.
2. شريط سفلي **عائم** (pill) بحواف مستديرة ومسافة 16dp من الأطراف، أيقونة + تسمية، مع تحديد بصري للتبويب الحالي.
3. تحويل الإعدادات من `Dialog` إلى شاشة فرعية كاملة، واختيار المصادر إلى شريط سفلي (bottom sheet).
4. نقل حالة البيانات الحالية كما هي داخل التبويبات (بلا إعادة كتابة منطق).
**معيار القبول:** التنقل بين التبويبات فوري، حالة التبويب (موضع التمرير) محفوظة، ولا شيء يغطي الشاشة كنافذة إلا القوائم الصغيرة.

### المرحلة 1 — الشاشة الرئيسية بأسلوب Nuvio
1. **هيرو متحرك (Pager)**: 5–8 عناصر من أول كتالوج + المفضلة، خلفية بعرض الشاشة، تدرّج أسود للأسفل، اسم العنصر، سطر واحد `مسلسل • دراما • 2026`، زر أبيض واحد «عرض التفاصيل»، نقاط تنقّل (النقطة النشطة تصبح شريطًا).
2. **صف «أكمل المشاهدة»**: بطاقات أفقية 16:9 مع شريط تقدّم، `S1 E4`، وشارة «بقي 42 د».
3. **صف بوسترات لكل كتالوج إضافة** بعنوان القسم (`الأكثر شعبية · أفلام`).
4. **شيمر تحميل** بدلًا من مؤشر دائري، ورسالة فراغ تسمّي السبب («لا يوجد كتالوج: أضف Cinemeta»).
**معيار القبول:** الرئيسية تُقرأ كتطبيق بث حقيقي حتى مع إضافة واحدة، وبلا نص تقني.

### المرحلة 2 — شاشة التفاصيل الكاملة
1. خلفية ضبابية بعرض الشاشة + هيدر عائم شفاف (رجوع، مفضلة، مشاركة).
2. بوستر + شعار + شريط معلومات (سنة، مدة، تقييم، تصنيف).
3. زر «▶ مشاهدة» + زر «+ حفظ» في صف واحد.
4. «القصة» مع «المزيد»، ثم **المواسم** كأقراص، ثم قائمة الحلقات بصور مصغّرة وتقدّم لكل حلقة.
5. زر المصادر يفتح شريطًا: الجودة/الصيغة كشارات، اسم الإضافة/المزوّد، ترتيب حسب الجودة، وتذكّر آخر رابط ناجح.
**معيار القبول:** يمكن الانتقال من الرئيسية إلى التشغيل بأقل من ثلاث لمسات.

### المرحلة 3 — المشغّل: أكبر فرق محسوس
1. غلاف تحكم بملء الشاشة يختفي بعد 3 ثوانٍ (بدل النوافذ الحالية).
2. إيماءات: نقرة مزدوجة يمين/يسار للتقديم، سحب عمودي لليمين للصوت ولليسار للإضاءة، شريط تقدّم كبير.
3. شريط سفلي: الترجمة، الصوت، الجودة، سرعة التشغيل، نسبة العرض، الصورة داخل الصورة.
4. بطاقة «الحلقة التالية» قبل النهاية بـ30 ثانية + تشغيل تلقائي.
5. تأخير الترجمة (±) وتكبير الخط، واختيار مسار الصوت صراحة.
**معيار القبول:** لا يظهر أي صندوق Compose أثناء المشاهدة.

### المرحلة 4 — تبويب البحث والمكتبة
1. بحث في تبويب مستقل: حقل ثابت أعلى، سجل بحث، نتائج مجمّعة حسب الإضافة، حالة فراغ واضحة.
2. مكتبتي: شبكة بوسترات 3 أعمدة، مفاتيح `المحفوظة / قيد المشاهدة`، علامات ✓ للحلقات المشاهدة، وعدّاد.

### المرحلة 5 — الإعدادات بترتيب Nuvio
قائمة جذرية بمجموعات: المظهر (لون مميز + OLED)، التشغيل (المشغّل، الترجمة الافتراضية، الصوت، السرعة)، المصادر (Stremio، Nuvio، TMDB)، حول التطبيق. كل مجموعة صفحة مستقلة.

### المرحلة 6 — صقل
انتقال البوستر إلى شاشة التفاصيل (shared element)، اهتزاز خفيف عند الحفظ، تدرّج على البوسترات، دعم RTL كامل، وتحقّق VoiceOver.

## الترتيب الموصى به
المرحلة 0 + 1 في **بناء واحد** (≈ 600 سطر Compose، بلا أي مكتبة جديدة)، ثم 2، ثم 3. بعد كل مرحلة يصلك رابط تثبيت جديد برقم بناء متزايد.

## ما لا تحلّه هذه الخطة
الواجهة لا تجلب محتوى. المصادر التي تحتاج تورنت (أو التي تحتاج `cheerio`/`crypto-js`) تبقى خارج التشغيل حتى نبني محرك بث محلي أو نوسّع بيئة JavaScript. هذه بند منفصل يُقرَّر بعد اكتمال الواجهة.
